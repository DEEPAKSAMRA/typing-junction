Install मदद

Install करते समय चेतावनी आए तो घबराएँ नहीं

Typing Junction नया software है और अभी इस पर Microsoft का paid “digital signature” नहीं है। इसलिए Windows या browser पहली बार इसे “अनजान app” मानकर चेतावनी दिखा सकते हैं। यह सामान्य है — नीचे दिए कदम अपनाएँ।

1

Browser में “Keep” चुनें

Chrome/Edge download के बाद “commonly downloaded नहीं है” लिख सकता है। Download list में ⋮ या … पर क्लिक करें → Keep (Edge में Keep → Keep anyway)।

2

“Windows protected your PC” में More info दबाएँ

Setup खोलते ही नीली window आ सकती है। Don't run न दबाएँ — बाईं ओर लिखे More info पर क्लिक करें।

3

Run anyway दबाएँ

अब App का नाम TypingJunction_Setup.exe दिखेगा और नीचे नया बटन Run anyway आएगा। उस पर क्लिक करें — setup शुरू हो जाएगा (Admin password नहीं चाहिए)।

4

Antivirus (Quick Heal, Avast, K7 आदि) file रोक दे तो

कुछ antivirus नए software को अपने आप रोक देते हैं। तब:

  • Antivirus खोलें → Quarantine / Virus Vault में TypingJunction_Setup.exe को Restore करें, या
  • Antivirus में Exclusion / Exception में Download folder वाली setup file जोड़ें, फिर setup दोबारा चलाएँ।
  • दिक्कत आए तो WhatsApp करें — screen share से मदद की जाएगी।

FAQ

अक्सर पूछे जाने वाले सवाल

क्या यह RSSB का official software है?

नहीं। Typing Junction एक स्वतंत्र practice software है, RSSB या किसी सरकारी संस्था से इसका कोई संबंध नहीं है। इसे RSSB के प्रकाशित परीक्षा निर्देशों के अनुसार परीक्षा जैसा अनुभव देने के लिए बनाया गया है। परीक्षा की आधिकारिक जानकारी के लिए हमेशा RSSB की website देखें।

अंक कैसे गिने जाते हैं?

RSSB के निर्देशों के अनुसार – English में हर सही शब्द के 0.05 और हिन्दी में 0.0625 अंक; गलत, छूटे या दोहराए शब्द, spacing, case, punctuation व मात्रा की गलती पर उस शब्द के अंक नहीं मिलते। दक्षता में हर सवाल के तय अंक, और दिए गए text में बदलाव या अतिरिक्त formatting पर उस काम के अंक शून्य।

Free trial में क्या मिलता है?

हिन्दी व English टाइपिंग के 3-3 passages, MS Word व MS Excel दक्षता का Set 1 और पूरा Full Mock 1 – ताकि आप खरीदने से पहले पूरा अनुभव देख सकें।

MS Office नहीं है तो?

टाइपिंग की practice बिना Office के होती है। दक्षता (Word/Excel) practice असली MS Office में होती है, इसलिए उसके लिए PC में Word व Excel installed होने चाहिए।

Install करते समय “Windows protected your PC” क्यों आता है?

यह Windows की सामान्य सुरक्षा चेतावनी है जो हर उस नए software पर आती है जिस पर अभी paid digital signature नहीं है। More info → Run anyway दबाकर install करें। पूरी विधि चित्रों सहित Install मदद में है।

क्या mobile पर चलेगा?

अभी यह Windows PC/laptop के लिए है, क्योंकि परीक्षा भी computer पर keyboard से होती है।

Lifetime licence दूसरे PC पर चलेगा?

Licence उस PC के Machine ID से जुड़ा होता है जिसका ID आप भेजते हैं। PC बदलने पर WhatsApp पर संपर्क करें।

भुगतान के बाद key कितनी देर में मिलती है?

भुगतान का screenshot और Machine ID WhatsApp पर भेजने के बाद key भेजी जाती है – आम तौर पर कुछ ही समय में।
